SYNTHESIS RULES

Rule 1 — Evidence Integration
Weight evidence across stages:

- Stage 1 config → HIGH (authoritative C2/family source)
- Stage 3 + 4 YARA → HIGH (direct malware confirmation)
- Stage 5 behavior → HIGH (execution proof)
- Stage 6 network → HIGH (external validation)
- Stage 2 target → MEDIUM (static indicators)

---

Rule 2 — Confidence Scoring
- HIGH (7.0–10.0): Multi-stage confirmation (config + memory + behavior)
- MEDIUM (4.0–6.9): Partial correlation
- LOW (1.0–3.9): Weak or single-source evidence

Set `confidence_score` as float (0.0–10.0).

---

Rule 3 — Conflict Resolution
- Stage 1 config overrides network mismatches
- Memory evidence > behavior API absence
- YARA family matches override static indicators
- Signing claims must be treated as potentially spoofed if conflicting

Document conflicts in `analyst_notes`.

---

Rule 4 — Threat Intelligence Usage
- ONLY include external TI if provided in input
- NEVER hallucinate TI data
- If TI contradicts sandbox → prioritize TI for CLEAN verdicts
- Otherwise prioritize sandbox evidence

---

Rule 5 — MITRE ATT&CK Mapping
Aggregate techniques from:
- YARA detections (Stage 3/4)
- Process behavior (Stage 5)
- Network behavior (Stage 6)

Group into:
- Execution, Persistence, Privilege Escalation
- Defense Evasion, Credential Access
- Discovery, Lateral Movement
- Command and Control, Exfiltration, Impact

---

Rule 6 — IOC Consolidation
Merge and deduplicate IOCs from:
- Stage 1: config hashes, C2
- Stage 2: file hashes
- Stage 4: memory PE dumps
- Stage 5: mutexes, file paths, registry keys
- Stage 6: domains, IPs

---

Rule 7 — Incident Response Guidance
Generate actionable steps:

- Persistence → remove Run keys / scheduled tasks
- Injection → dump processes / capture memory
- C2 → block domains/IPs at firewall
- Dropped files → quarantine artifacts
- Services → disable and analyze binaries

---

Rule 8 — Investigation Priority
- CRITICAL → active C2 + persistence + data theft
- HIGH → confirmed malware + evasion + injection
- MEDIUM → suspicious behavior only
- LOW → benign activity

Include hunting queries for SIEM/EDR.

---

Rule 9 — Final Verdict Logic
- MALICIOUS → confirmed family OR strong multi-stage evidence
- SUSPICIOUS → partial indicators, no full confirmation
- CLEAN → benign + TI confirms clean
- INCONCLUSIVE → insufficient data
