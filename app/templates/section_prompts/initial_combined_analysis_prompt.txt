ANALYSIS LOGIC & DECISION RULES

Rule 1 — Malware Family Identification
Set malware_family ONLY if identified from:
- cape.configs[].family
- cape.payloads[].cape_type
- cape.payloads[].cape_yara[].name

If no reliable family identifier exists:
- Set value to null

Do NOT guess malware families.

---

Rule 2 — C2 Extraction Logic
Extract C2 infrastructure ONLY from CAPE config fields:
- cape.configs[].config_data.Hosts
- cape.configs[].config_data.Host
- cape.configs[].config_data.C2
- cape.configs[].config_data.Server
- cape.configs[].config_data.Address

If Ports field exists, combine as:
- ip:port
- domain:port

If no valid C2 data exists:
- Return []

Do NOT derive C2 from network traffic or any external/non-CAPE sources.

---

Rule 3 — Threat Level Classification

CRITICAL:
- Malware config extracted
- C2 identified
- Process injection observed

HIGH:
- Known malware family detected
- Injection OR config extraction present

MEDIUM:
- Suspicious indicators or payloads, no confirmed family

LOW:
- Minimal or weak malicious indicators

INFORMATIONAL:
- Timeout or analysis failure prevents reliable assessment

---

Rule 4 — Signature Statistics
If signature data is available:
Calculate execution ratio:
(non_zero_signatures / total_signatures) * 100

Format example:
"11% executed (80/723), 89% zero-time"

If more than 80% of signatures show zero execution time:
Mention:
- poor execution coverage
- possible environment or termination issues

---

Rule 5 — Strict Scope Control
Do NOT infer or mention:
- DNS activity
- HTTP/HTTPS traffic
- persistence mechanisms
- scheduled tasks
- registry persistence
- API call behavior
- credential theft
- lateral movement
- data exfiltration

Only use explicit CAPE extraction data.

---

Rule 6 — Timeout Handling
If timeout_occurred = true:
- Mention analysis may be incomplete
- Describe possible impact on visibility
- Reference slowest modules if available
- Reduce confidence accordingly

---

Rule 7 — Executive Summary Style
summary_paragraph must:
- Be 2–3 sentences
- Use SOC analyst terminology
- Include (if available):
  - malware family
  - injection activity
  - config extraction status
  - C2 indicators

---

IOC types:
