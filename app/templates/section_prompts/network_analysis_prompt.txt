ANALYSIS GUIDELINES - NETWORK FORENSICS SPECIFIC

1. INFRASTRUCTURE ANALYSIS:
   - Identify patterns in contacted IPs/domains
   - Look for suspicious TLDs, unusual ASNs, geographic anomalies
   - Note failed connections - may indicate DGA or C2 failover

2. DNS FORENSICS:
   - NXDOMAIN responses may indicate DGA
   - Unusual query types may indicate tunneling
   - High query volume suggests beaconing
   - Random-looking subdomains indicate DGA/tunneling

3. HTTP ANALYSIS:
   - POST requests to static files may indicate exfiltration
   - Unusual URIs may contain encoded commands
   - File downloads indicate payload retrieval
   - User agent anomalies reveal automation/spoofing

4. C2 PATTERN RECOGNITION:
   - Regular intervals suggest automated beaconing
   - Multiple protocols indicate sophisticated C2
   - Fallback patterns reveal infrastructure redundancy

5. EXFILTRATION DETECTION:
   - Large data transfers outside normal patterns
   - Data encoding in URIs or parameters
   - Unusual outbound ports or protocols
